# Corrientes Geostróficas en Aguas Colombianas Yuliana Paola Romo.

Análisis de perfiles oceanográficos (temperatura, salinidad, densidad) y corrientes geostróficas en La Guajira, Pacífico colombiano y Golfo de Salamanca.

## Requisitos

Instalar las dependencias necesarias:

```bash
pip install netCDF4 numpy matplotlib gsw scipy
```
